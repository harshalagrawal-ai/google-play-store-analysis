# 📱 Google Play Store Data Analysis

An end-to-end Data Analytics project that analyzes Google Play Store application data using **Microsoft Excel, MySQL, and Power BI**.

## 📌 Project Overview
This project explores Google Play Store data to identify trends in app categories, ratings, reviews, installs, and app types.

## 🎯 Objectives
- Clean and prepare the raw dataset in Excel
- Analyze the data using SQL
- Build dashboards in Excel and Power BI
- Generate business insights

## 🛠️ Tools Used
- Microsoft Excel
- MySQL
- Microsoft Power BI

## 🔄 Workflow
Raw Dataset → Data Cleaning → Cleaned Dataset → Excel Dashboard → SQL Analysis → Power BI Dashboard

## 📈 Key Insights
- 8,893 applications analyzed
- 34 app categories
- Average rating: 4.19
- Free apps greatly outnumber paid apps
- Family and Game are among the largest categories
- Top apps generate very high review counts
